# 🎓 Student Management System

A Python Flask-based Student Management System developed using Object-Oriented Programming (OOP) and File Handling.

---

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
- File Handling (JSON)
- Object-Oriented Programming
- Exception Handling
- Responsive UI
- Modular Code Structure

---

## Technologies Used

- Python 3
- Flask
- HTML5
- CSS3
- JavaScript
- JSON

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Student_Management_System.git
```

Move into the project

```bash
cd Student_Management_System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
